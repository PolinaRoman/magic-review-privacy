Magic Review — политика конфиденциальности

Контакт по вопросам обработки данных: polinaromanenko777@gmail.com. Обновлено 17.11.2026.

Magic Review сравнивает выбранную пользователем веб-страницу с макетами Figma. При работе расширение обрабатывает адрес и содержимое выбранной страницы, её скриншоты, геометрию и оформление элементов, данные выбранных макетов Figma, настройки проектов, замечания и сведения, которые пользователь вводит в паспорт отчёта.

Сверка выполняется локально в браузере. Результаты и изображения сохраняются в IndexedDB текущего профиля Chrome; токен Figma и настройки — в локальном хранилище расширения. Токен передаётся официальному API Figma для авторизации запросов выбранных макетов. Изображения макетов загружаются с адресов, предоставленных Figma. Расширение не отправляет снимки сайта или отчёты на сервер разработчика и не использует внешние AI-сервисы, аналитику или рекламу.

Пользователь может скачать выбранные замечания и изображения в JSON. Скачанный файл хранится там, куда его сохранил пользователь. При импорте через Magic Review Unpacking содержимое отчёта добавляется в выбранный Figma-файл и становится доступно согласно правам доступа к этому файлу. Figma-плагин не выполняет собственных сетевых запросов; сохранение документа обеспечивает сама Figma.

Данные проектов не удаляются автоматически. Проект можно удалить с подтверждением в интерфейсе; токен — удалить в настройках. Удаление проекта не удаляет ранее скачанные JSON или объекты, уже добавленные в Figma. Удаление расширения удаляет его локальное хранилище средствами Chrome. Токен можно отозвать в настройках аккаунта Figma.

Используйте инструмент на страницах и макетах, к которым у вас есть доступ. Перед экспортом проверьте, какие данные попадают в отчёт и кому доступен итоговый файл Figma.
